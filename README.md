# LIGHT 的工具箱

微信原生小程序，提供证件照、幸运转盘、PDF 合并和图像压缩。后端使用微信云开发，**无需自购服务器或域名**；同时保留 Express / SQLite 本地评审服务。

正式定价为 **¥1 / 次、¥9.9 / 30 天月卡，手动续费**。价格由云端配置，后续调价不改代码、不重传小程序，操作见 [PRICING.md](docs/PRICING.md)。每次成功处理消耗一次，失败释放预留次数；月卡覆盖四项工具。

当前代码使用 `production / cloud` 配置。最近一次记录的云端核验为 2026-10-12：正式价格已恢复，运行配置已启用；当时未提交审核或公开发布小程序，详见 [正式运行配置](docs/PRODUCTION.md)。Android 单次卡和 iPhone 月卡首次付款、权益到账及发货确认已有记录；真实退款验收暂缓，真机隐私声明、选图及相册保存仍需独立复测。GitHub 源码公开与小程序上架是两项独立操作。

## 本机运行

需要 Node.js 24 或以上。首次克隆后安装依赖并从示例创建本机配置；已有 `.env` 时保留原文件：

```powershell
npm ci
npm ci --prefix cloudfunctions/lightToolbox
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
npm run dev
```

打开 <http://127.0.0.1:8787>。浏览器页面是方便评审的本地界面，与小程序共享真实文件处理 API；它不是微信模拟器。本地模式仅监听 `127.0.0.1`，免费试用真实工具，不创建支付订单，不伪造会员。

```powershell
npm test
npm run check
```

`check` 覆盖源文件、完整页面结构、本地资源；找到本机微信编译器时额外编译 WXML/WXSS。它不替代真机测试。

## 公开仓库与独立部署

仓库包含源码、测试、部署脚本、非敏感资源及脱敏后的验证文档。`.env`、`.env.payment`、`.env.portrait`、数据库、日志、`output/` 和开发者工具私有配置均不上传；文档引用的本机回执不随仓库分发。

独立部署时请配置自己的微信 AppID、云环境和商品。当前 `project.config.json`、`miniprogram/config.js`、`cloudbaserc.json` 及部署脚本仍保留原项目的应用与环境标识；部分测试和检查也显式核对原 AppID，迁移时需同步调整。支付和人像分割凭据只从服务端环境读取，配置说明见 [SETUP.md](docs/SETUP.md) 与 [CLOUDBASE.md](docs/CLOUDBASE.md)。

## 正式接入

1. 填写项目根目录 `.env` 中的私密配置。**不要把密钥发到聊天、前端或 Git。**字段说明见 [接入与部署](docs/SETUP.md)。
2. 在微信后台确认个人主体「工具」类目、认证、备案和虚拟支付开通；创建并发布商品，保持微信道具价格与服务端 `LIGHT_PRICE_SINGLE_FEN` / `LIGHT_PRICE_MONTH_FEN` 一致。
3. 云函数、业务集合、索引、私有存储和人像分割已接通；小程序使用 cloud transport 和原生云存储下载。按 [云开发说明](docs/CLOUDBASE.md) 完成支付回调及隐私指引配置。
4. 在 Nightly 登录并授权 Codex，编译模拟器、真机扫码；最后小额真实支付验证「付款 → 通知/查单 → 权益 → 退款」。

完整步骤和已知边界见 [SETUP.md](docs/SETUP.md)，本次验证证据见 [VALIDATION.md](docs/VALIDATION.md)。

历史验证：2026-10-12 记录了 100 项 Node 测试、生产配置脚本隔离测试及原生 WXML/WXSS 编译通过。四项工具已有 Nightly 真实云函数处理和结果下载记录；证件照还验证了真实腾讯 BDA 调用，一寸蓝底输出为 295×413 px / 300 DPI。完整证据与边界见 [VALIDATION.md](docs/VALIDATION.md)；预置测试素材不代表真机选图准入通过。

## 可观测性与数据处理

- 本地 HTTP API 返回 `X-Request-ID`；云函数响应及错误 JSON 携带 `requestId`，错误同时包含 `code` / `message`。
- 日志串联请求、处理任务、支付订单与腾讯人像分割 RequestId；不输出 OpenID、会话密钥、原始文件或抽奖名单。
- 转盘图片与配置保存在当前设备，图片不上传；每轮仅提交选项编号/文字/权重及转盘名称。配置保存后可重复使用，替换或删除选项并保存时清理旧图片。更换设备不会同步。
- 其他工具本地原始文件仅进入请求内存，清理周期 1 分钟；云端原件临时进入私有存储，成功即删、中断/失败到期清理，周期 5 分钟。两者结果均保留 1 小时；云端下载先校验归属/期限，再通过微信原生私有存储下载。实际删除前，文件创建者仍拥有底层存储读取权限。
- 数据库事务预留单次权益。任务失败或服务重启中断时释放次数；已完成任务的相同请求返回原结果，不重复扣次。
- 月卡正常续购顺延。退款撤销对应订单权益；部分退款进入 `refund_review` 并暂停对应权益，需人工核对。
- 本地服务使用单实例 SQLite WAL 与启动锁；云开发版本改为共享 NoSQL 事务，用户 revision 与平台单号 receipt 文档共同约束并发。
- 上线应安排数据备份、日志轮转和错误告警，备份不可包含过期结果文件或名单。
