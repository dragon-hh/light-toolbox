## 格式提示依据

元信息检测仅用于本机显示，服务端仍执行原有图片解码与格式校验。PNG 依据 [W3C PNG 规范](https://www.w3.org/TR/png-3/)，WebP 依据 [Google WebP 容器规范](https://developers.google.com/speed/webp/docs/riff_container)。测试覆盖 JPEG、RGBA/无透明 PNG、调色板 PNG、有损及无损 WebP，并与实际服务端使用的 Sharp `hasAlpha` 结果对照；原文件已足够小的情况仍以最终结果提示为准。
